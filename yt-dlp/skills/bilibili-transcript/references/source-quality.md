## 来源优先级

按以下顺序寻找，命中合格来源即停止：

1. UP主、节目、工作室或嘉宾机构发布的文字版
2. 联合出品方、首发媒体或明确获得授权的完整转载
3. 播客 RSS、YouTube、小宇宙等同一节目分发页给出的官方文字版链接
4. 搜索引擎找到的第三方转载或整理

不要把 Podscan、HappyScribe、Transcript LOL、自动摘要站等第三方 ASR 聚合页当作更高质量来源。它们只有在补充说话人线索时才有参考价值，不能取代B站字幕。

## 四档判定

| 档次 | 判据 | 用法 |
|---|---|---|
| A 完整逐字稿 | 第一方/授权来源；有说话人；开头、中段、结尾与视频相符；覆盖基本完整 | 取代字幕，保留原文结构直接采用 |
| B 官方编辑稿 | 第一方正式文字版，但明确删节、整理或改写 | 直接作为“官方编辑稿”采用，不能标成逐字实录 |
| C 第三方整理 | 来源关系不明、第三方 ASR、个人摘要 | 只作专名或说话人参考，正文仍用B站字幕 |
| D 不可用 | 付费墙残文、搜索摘要、仅前几段、版本不同 | 放弃 |

用户要求“文稿”时，A 档和高质量 B 档都优先于重新整理平台 AI 字幕。两者的区别必须写进文首：A 档忠于原话，B 档代表节目方编辑后的正式文字呈现。

## 核验清单

### 来源关系

- 页面作者、公众号或网站是否属于节目、UP主、嘉宾机构或联合出品方？
- 若为媒体转载，是否注明来源、作者或授权？
- 标题、嘉宾、发布日期是否对应同一期？

### 版本一致

- 视频是否为纯享版、精华版、完整版或分P？
- 抽查开头、中段、结尾各一处，确认文稿不是另一次剪辑。
- 如果官方稿删去广告、寒暄或重复表达，可接受，但要标“官方编辑稿”。

### 完整性

- A 档应覆盖视频的开头、中段和结尾，并保留主要问答。
- 只有搜索引擎片段、公众号导语或少量摘录，不算完整文稿。
- 不要只用字数比判断中文稿；必须做三点内容抽查。

### 结构质量

- 是否有明确说话人、章节或问题标题？
- 专名是否显著优于平台 AI 字幕？
- 是否保留重要限定、否定和转折，而非营销式摘要？

## 张小珺商业访谈录范例

这类节目是“必须找现成稿”的典型：

- B站视频可能只给节目简介，不给公众号外链。
- 同一期在 YouTube 或播客分发页常会写“完整对谈文字版”并给链接。
- 官方公众号常见名称包括“语言即世界 language is world”或“张小珺”；联合媒体也可能转载全文。

检索顺序：

```text
"<精确节目标题>" 文字版
"张小珺" "<嘉宾姓名>" 全文 OR 实录
site:mp.weixin.qq.com "<嘉宾姓名>" "语言即世界"
```

例如标题为“张小珺对话李想”时，若找到节目方完整文字版或注明来源的媒体全文，核对开头、中段、结尾后直接作为 A/B 档底本；不要再从 `ai-zh` 重新生成一篇摘要式文稿。

## 文首格式

现成稿文首至少写：

```markdown
> 节目：……
> 嘉宾：……
> 发布日期：……
> 原视频：……
> 文字来源：……
> 底本：A档完整逐字稿 / B档官方编辑稿；已核对视频版本与完整性。
```

正文保留来源原有层级、说话人和段落。只做必要的 Markdown 适配、明显错字修正与来源标注，不另写 AI 摘要覆盖原稿。
