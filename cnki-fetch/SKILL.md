# 知网全文抓取

本目录若有 `local.md`（本机部署约定：路径、网络、配套工具），先读它；与本文冲突时以它为准。

> **给 agent 的硬约束**（三条，请勿绕过）：
> 1. **访问知网一律走本 skill 的 `cnki` 命令**。不要另开 Chrome、不要用 Chrome MCP、不要用 WebFetch 抓 kns.cnki.net——普通浏览器指纹会撞验证码，而且拿不到登录态。需要写自定义脚本时，用本 skill 的 `.venv/bin/python` 并 `import cloakbrowser`。
> 2. **PDF／CAJ 能直接下**，`cnki <篇名>` 默认就是。撞点选码的只有「HTML阅读」那一个链接（`a.icon-html` → bar.cnki.net），下载走另外两个入口，无验证码。别把三者混为一谈。
> 3. **核对抓下来的正文先看缓存**：`cache/<检索词>.html` 就是知网返回的原始 DOM，数一数 `sup.footNote` 就知道脚注抓全没有。不要为此去开浏览器。`cache/` 不是临时文件，别当垃圾清掉。

**默认只下原版 PDF**，用户点名要 DOCX 时才加 `--docx`（PDF＋DOCX 双落盘）。默认无头运行、不弹窗，检索页拼图滑块自动破解。PDF 是出版方定稿，引用与存档以它为准；DOCX 从知网排版 XML 生成，供阅读、检索与入库，正文、章节层级、脚注、原生表格、字形图一并带出。XML 会替换表格图里的字、偶尔漏标脚注，所以出 DOCX 时仍连 PDF 一起下。DOCX 不收英文题名、英文作者、英文摘要；各刊自带的作者简介挂成作者行的星号脚注，刊物没给就不出。

通道选择的原因、版式规格、台账字段、改代码前必看的坑、批量提取正文的写法：[references/dev-notes.md](references/dev-notes.md)。

## 一、抓取

```bash
# 单篇：按篇名检索并抓取
cnki 先秦盟、诅关系及其礼制异同

# 先看候选（含「有HTML全文 / 仅PDF」标记），再决定抓哪条
cnki --search-only 盟诅

# 命中多条时指定第几条（从 0 起）
cnki 盟诅 --index 3

# 批量：一行一个篇名，默认读 skill 目录下的 待抓.md
cnki -f
cnki -f /path/to/清单.md

# 换输出目录（默认 ~/Downloads/知网文献，长期改用 .env 的 CNKI_OUTPUT_DIR）
cnki 篇名 -o ~/Desktop

# 默认只下原版 PDF
cnki 篇名
cnki 篇名 --docx              # PDF ＋ DOCX 双落盘
cnki 篇名 --no-pdf            # 只要 DOCX
cnki 篇名 --caj               # 原版下 CAJ 而非 PDF

# DOCX 只改版式不重新联网（用本地缓存重排，调格式时用）
cnki 篇名 --cache

# 环境自检 / 人工过验证
cnki --doctor
cnki --open
```

篇名支持简体输入，繁体文章也能命中。

## 二、检索（只列不抓）

给了 `-a` / `-j` / `-k` 任一项就是列表模式：

```bash
# 按篇名找一个题目下的所有文章
cnki -t 论衡 -n 120

# 某刊最新一期有哪些文章
cnki -j 文学遗产 --latest

# 某刊近两年，最多 60 条
cnki -j 文史 --since 2024 -n 60

# 某作者最近五年发了什么
cnki -a 张三 --since 2021 -n 40

# 同名作者混杂时，按学科筛（最有效）
cnki -a 张三 --facets                    # 先看这个检索有哪些分面可选
cnki -a 张三 --field 中国古代史
cnki -a 张三 --field 中国古代史 --core CSSCI

# 按主题
cnki -k 侯马盟书 -n 30

# 检索结果直接写进待抓清单，再批量抓
cnki -j 文学遗产 --latest --to-list
cnki -f
```

| 选项 | 说明 |
|---|---|
| `-t` `-a` `-j` `-k` | 篇名 / 作者 / 文献来源 / 主题（知网 TI、AU、LY、SU 字段） |
| `--type` | **论文**＝期刊+辑刊（默认）/ 期刊 / 辑刊 / 学位 / 全部 |
| `--no-fanti` | 关掉繁简变体检索（默认会做） |
| `--latest` | 只列最新一期（同一发表日期的全部），配合 `-j` |
| `--since` `--until` | 年或年月，如 `2021`、`2021-06` |
| `-n` | 最多列多少条，默认 20；超过一页会自动翻页 |
| `--facets` | 先列出本次检索可用的分面：主题 / 来源类别 / 学科，带条数 |
| `--field` | 按**学科**筛，如「中国古代史」「中国文学」，走知网左侧分面 |
| `--core` | 按来源类别筛：CSSCI / 北大核心 / AMI / CSCD |
| `--source` | 客户端过滤，只留文献来源含该词的 |
| `--to-list` | 结果写进 `待抓.md`（跳过已在清单里的） |

- 结果按发表时间**倒序**；行尾标「有AI阅读入口 / 仅PDF」——后者抓不了 DOCX，只能下 PDF。
- **翻页判停**：没有下一页、翻页后首条未变、越过 `--since`、`--latest` 下日期变化、凑够 `-n` 条即停，最多 40 页；每次翻页等首条真的换掉再取。别信 `.search-page` 里的 `<em>`，那不是总页数。
- **繁简：知网不做归一**，字面精确匹配，姓名尤其坑（规范繁体里「吴」仍作「吴」，opencc 给的「吳揚廣」一条也查不到）；`+`、空格、分号做 OR 全都无效。所以**默认对检索词逐字取简/繁做笛卡尔积**，全部查一遍再按「篇名＋日期」合并去重（8 个变体约 50 秒）；变体超过 8 个时退化为「原词／全繁／全简」三种。
- **文献类型**：库代码 CJFQ＝期刊、CCJD＝辑刊、CDMD＝学位论文（博＋硕），走 URL 的 `crossDbcodes`。**辑刊不能跟学位论文一起排除**——《文史》《历史文献研究》《经学文献研究集刊》这类都在 CCJD，是文史研究的重要发表阵地。
- **同名作者**：AU 字段只认姓名，常见姓名会把医学、化工、建筑的同名者一起带出来。**用 `--field` 按学科筛最干净**，先 `--facets` 看可选学科与条数；`--field` 和 `--core` 可叠加（按左侧分面 `dl[groupid] > dd li` 逐个点选）。

## 三、前置条件与安装

| 条件 | 说明 |
|---|---|
| 机构权限 | 必须。机构网络直连或机构 VPN，页面右上角显示「××大学图书馆」等机构名才有全文权限；没有时检索能用，AI 阅读页取不到正文 |
| 网络 | 知网要走国内机构出口。**入口脚本会先清掉 `HTTP(S)_PROXY`／`ALL_PROXY`**，免得 shell 里导出的代理把请求送出境（知网一律回 401）；系统级全局代理／TUN 也要让 `cnki.net` 直连 |
| 系统 | macOS 上开发与验证；Linux 应可用但未实测；Windows 不支持（用到 `fcntl`） |
| Python | 3.10+，推荐用 [uv](https://github.com/astral-sh/uv) 建 `.venv` |
| 浏览器 | [cloakbrowser](https://github.com/CloakHQ/CloakBrowser)（随 requirements 安装）：反检测 Chromium，Playwright 接口。首次启动自动下载内核到 `~/.cloakbrowser`（约 350 MB）；免费版同时只能开一个会话 |
| 使用边界 | 只抓本机构有权访问的内容，遵守知网与所在机构的使用条款；按需取用，别做全库批量 |

安装（在技能目录里执行）：

```bash
uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt
#（没有 uv：python3 -m venv .venv && .venv/bin/pip install -r requirements.txt）
ln -s "$PWD/cnki" /usr/local/bin/cnki    # 或 ~/.local/bin 等任一 PATH 目录；不链也可用 ./cnki
cp .env.example .env                      # 可选：改落盘目录
cnki --doctor                             # 自检依赖、登录态与输出目录
```

新建的 `profiles/cnki` 首次检索必遇拼图滑块，自动破解偶尔不过（报「验证码未通过」）：重跑一次，或 `cnki --open` 人工滑一次。

**401 十有八九是出口不对，不是真没权限**：检索和元数据都正常，偏偏 AI 阅读页回 401，看起来就像学校没订这个刊。自己写脚本直接调 `lib/fetch.py` 时也要 `unset` 那几个代理变量。

## 四、输出与局限

- **文件名** `篇名_作者_刊名年-期.pdf`／`.docx`（多于 3 位作者取首位＋「等」；无期号只到年份）。DOCX 全宋体、内置 Heading 样式导航窗格可跳转、真·页下脚注全篇连续编号；**照原刊不动**章节措辞与层级、注释引书格式、繁简、摘要关键词的有无；繁简以正文为准，来源行与字段名跟随。
- **统一台账** `<输出目录>/抓取记录.csv`（其下各刊目录共用；自定义输出目录优先用已有上级台账，否则在输出目录创建）：UTF-8 BOM，每篇一行，重抓更新原行。「通过」仅表示缓存 DOM → DOCX 验收通过，**不等于已逐项校对原刊 PDF**；存在缺图占位或原始 XML 本身缺图时文件保留、验收状态为 `review_required`，不可当完全无损。续抓核对 DOCX 校验值和生成版本，「待核对」仍视为已生成，避免反复抓缺图文章。分类移动后台账中同名成果唯一则复用该位置；多个目录已有同名成果时提示用 `-o` 指定刊物目录，不自动挑选或覆盖。**不要手工删改程序使用的列名、路径或验收字段**，在 Excel 编辑保存后也应保持 UTF-8 CSV。
- **`--docx` 遇到无 HTML 全文时**：`--search-only` 标的「有AI阅读入口」只说明按钮在，不保证真有 XML 正文（老刊常按钮在、正文空），两道判断都过不了才算无 HTML 版。这类会记进 `待手工下载.md`：

  ```
  - [ ] 检索词｜篇名｜刊名 日期｜无 AI 阅读入口
  ```

  它们没有 XML 正文，出不了 DOCX，程序自动改下原版 PDF。

| DOCX 的局限 | 说明 |
|---|---|
| 无原刊页码 | XML 版没有分页信息。要引「见第 12 页」得回查 PDF；来源行给了页码范围 |
| 生僻字是图片 | Unicode 装不下的字，知网用小 jpg 替代。已按正文字号行内嵌入，位置准确，但不是文本 |
| 偶有取不到的字形图 | 极少数（百分之一量级）知网自己就没有，正文留 **▯** 占位并写入验收记录，需重新联网才能补；注意与原文表残缺的 □ 区分 |
| 老刊注文缺失 | 回溯录入的老文章（约 2010 年前）常只有正文，尾注标记在、注文不在，标点也多是半角 |
| 脚注可能漏标 | 完整性因篇而异。脚注异常少时会打印「！注意」——但**注少未必是漏标**，有的刊用文中夹注体例。拿不准就对一眼同时落盘的原版 PDF |
| 脚注编号 | 不少刊物原本每页从①重排，统一成全篇连续。这是刻意覆盖原刊体例 |
| 原生表格 | 已转换为 DOCX 表格；复杂 CSS 视觉效果可能简化，但单元格文字和合并关系保留 |

## 五、排障

| 现象 | 处理 |
|---|---|
| 检索无结果 | 篇名给全一点；或先 `--search-only` 用短词看候选 |
| 取不到正文 | 先查出口：`env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy -u all_proxy curl -s https://myip.ipip.net`，是境外 IP 就说明系统级代理／TUN 没让 `cnki.net` 直连。再确认机构权限：`cnki --open` 看右上角是不是「××大学图书馆」 |
| 滑块反复不过 | `cnki --open` 人工滑一次，会话存进 `profiles/cnki` |
| 想重排已抓的 DOCX | `cnki 篇名 --cache`，不联网，秒出 |
| 同一篇重抓 | 默认跳过已有文件，要覆盖加 `--redo` |
| 提示「忙」 | 另一个 cnki 在跑。浏览器只能开一个会话，第二个会被锁挡住——这是有意的，别并发 |
| 批次暂停 | 验证码未通过、登录失效、HTTP 401/403/429（401 先查出口 IP）、页面提示访问受限或页面超时未完成时立即暂停；进度写入输出目录的 `.cnki-progress.json`，不会继续刷新挑战 |
| PDF 下载超时 | 已内置 3 次重试。仍失败就隔几分钟再来，多半是知网侧限流 |
| 环境坏了 | 在技能目录重跑：`uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt` |

改版式只动 `lib/docx_builder.py` 头部的 `SZ_*` 常量，改完 `cnki 篇名 --cache` 立刻看效果；`--cache` 也会更新总表 `抓取记录.csv`，缓存重排不联网，缺失图片仍明确标记，不会伪装成完整正文。`profiles/cnki/` 是登录态，勿删。
